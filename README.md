# 译前工具 · 免费离线 JSON 本地化检查器

比较两份 JSON 语言文件，检查漏项、空文本和基础占位符差异。中文界面，AI 辅助开发的 v0.1 研究样品，免费试用，无需赞助或付费 API。

## 下载与三分钟试用

1. 回到仓库首页，点击绿色 **Code → Download ZIP**。
2. 解压后，用桌面浏览器打开 `localization-review.html`，无需安装 Node.js。
3. 点击“载入问题示例”，再点“开始检查”：应有 **4 条发现、3 条错误**。
4. 点击“载入修正示例”，再次检查：应有 **0 条发现**。
5. 修改输入后，旧报告应失效；重新检查后可导出 JSON 报告。

## 支持范围

- UTF-8 JSON 字符串及嵌套对象，每份最多 1 MiB、10000 条、32 层。
- 缺少键、空文本、额外键、与源文相同提示。
- 比较 `{name}`、`{0}`、`{{name}}`、`${name}` 基础变量的名称、格式及次数。
- 使用 JSON Pointer 定位条目，可导出 JSON 报告。

不支持数组、数值、布尔、null、完整 ICU/printf 模板；不检测重复 JSON 属性名、翻译语义、字体缺字或界面溢出。“未发现问题”仅表示已支持规则未发现问题，仍需实际项目人工验收。
