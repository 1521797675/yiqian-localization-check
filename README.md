# 译前工具 · JSON 本地化检查样品 v0.1

这是研究试用包，尚未收费发布。目标是比较两份 JSON 语言文件，找出机械性错误；不提供自动翻译。

## 包内文件
- `localization-review.html`：离线工具，使用桌面浏览器打开。
- `source.json`：源语言示例。
- `target-problems.json`：含问题的目标语言示例。
- `target-fixed.json`：修正后的示例。
- `expected-report.json`：由实际检查核心生成的问题示例报告。
- `人工验收清单.md`：工具未覆盖的发布前人工检查。

## 三分钟试用
1. 打开 HTML，点击“载入问题示例”，再点击“开始检查”。应显示 4 条发现，其中 3 条错误。
2. 点击“载入修正示例”，再次检查。应显示 0 条发现。
3. 修改任意输入，导出按钮应禁用；重新检查后恢复。
4. 导出 JSON 报告，确认内容对应本次检查。
5. 用文件选择按钮分别导入包内的源文件及问题文件，结果应与第一步一致。

## 支持范围
支持 UTF-8 JSON 的字符串及嵌套对象。每份最多 1 MiB、10000 条文本、32 层嵌套。
检查缺少键、空文本、额外键、相同原文提示，以及 `{name}`、`{0}`、`{{name}}`、`${name}` 的格式、名称和出现次数。
不支持数组、数字、布尔、null、重复 JSON 属性名检测、完整 ICU/printf 解析、翻译语义判断、字体检测或视觉溢出测量。
“未发现问题”只表示已支持的规则未发现问题。

## 数据处理
工具源码无联网和浏览器持久化代码；不改写原文件。导出报告包含键名，分享前请审查内部信息。请先使用包内虚构示例，不要上传公司或客户的机密文件。
